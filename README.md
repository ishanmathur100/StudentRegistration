# Student Registration Form (Java)

## 1. Project Overview
The Student Registration Form is a desktop application developed using Java Swing. It provides a graphical user interface (GUI) for entering and displaying student registration details.

## 2. Objectives
- To understand Java Swing and GUI development.
- To use components such as labels, text fields, radio buttons, checkboxes, and buttons.
- To implement event handling using `ActionListener`.
- To perform basic input validation.
- To understand how Java applications are compiled and executed.

## 3. Technologies Used
- **Programming Language:** Java
- **GUI Framework:** Java Swing
- **Event Handling:** `ActionListener`
- **Development Environment:** Visual Studio Code
- **Version Control:** Git and GitHub

## 5. Project Features
- Accepts student name and roll number.
- Allows gender selection using radio buttons.
- Provides a branch selection field.
- Includes a terms and conditions checkbox.
- Validates required fields before submission.
- Displays the entered registration details after successful submission.
- Provides a Reset button to clear the form.

## 6. Experiment / Project Name
**Experiment:** Design and implement a Student Registration Form using Java Swing.

**Aim:** To develop a GUI-based student registration application in Java using Swing components and event handling.

## 7. How to Run the Project

### Prerequisites
- Java Development Kit (JDK) installed.
- A terminal or Visual Studio Code.

### Compilation
Open the terminal in the project directory and execute:

```bash
javac StudentRegistration.java
```

### Execution
Run the following command:

```bash
java StudentRegistration
```

The Student Registration Form window should open.
